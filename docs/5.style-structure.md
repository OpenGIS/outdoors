# Style Structure

The outdoor map style is built on [OSM Liberty](https://github.com/hyperknot/openfreemap-styles) (OpenFreeMap fork) but replaces its visual layers with outdoor-first versions. Liberty's label, water, boundary, and rail infrastructure is kept intact, along with the landcover/landuse fills and the base path layer — 46 layers in total (see [Liberty Layers We Keep](#liberty-layers-we-keep)). Landcover, landuse, roads, buildings, and POIs are rebuilt for foot-based outdoor recreation (~15 outdoor road layers replace ~46 Liberty road layers, plus new outdoor-only layers).

The build pipeline lives in [`scripts/build.mjs`](../scripts/build.mjs). Each section has a feature toggle and named constants. Sections are ordered bottom to top, matching the MapLibre rendering stack.

## 2. DEM / DEM_HILLSHADE / DEM_TERRAIN

**Toggles:** `DEM` (master, default: `true`), `DEM_HILLSHADE`, `DEM_TERRAIN`  
**Function:** `applyDemSource`, `applyDemHillshade`, `applyDemTerrain`

Adds a `demSource` (raster-dem, Mapterhorn Terrarium-encoded WebP) and optional hillshade + 3D terrain layers.

- **Hillshade:** inserts at `waterStackIndex` (below water layers, above landcover). Fades in from z3 to z5.
- **Terrain:** sets `style.terrain` with exaggeration 1.5.

Constants: `DEM_SOURCE_URL` (`tiles.mapterhorn.com`), `DEM_SOURCE_ENCODING` (`terrarium`), `DEM_SOURCE_TILESIZE` (512), `DEM_SOURCE_MAXZOOM` (17), `TERRAIN_EXAGGERATION` (1.5), `HILLSHADE_EXAGGERATION`.

## 5. LANDCOVER_SUBCLASS

**Toggle:** `LANDCOVER_SUBCLASS` (default: `true`)  
**Function:** `applyLandcoverSubclass(style)`

Replaces Liberty's flat grass colour with subclass-based differentiation. Targets the `landcover_grass` layer's `fill-color`:

| Subclass                                    | Colour                             |
| ------------------------------------------- | ---------------------------------- |
| `heath`, `scrub`, `tundra`                  | `hsl(60, 30%, 78%)` (muted yellow) |
| Everything else (meadow, grass, park, etc.) | Default terrain grass              |

The existing `fill-opacity` (set by TERRAIN_PALETTE) is left untouched.

Constants: `COLOURS.LANDCOVER.HEATH`, `COLOURS.TERRAIN.GRASS`.

## 10. ROAD_SURFACE_AWARE

**Toggle:** `ROAD_SURFACE_AWARE` (default: `true`)  
**Function:** `applyRoadSurfaceAware(style)`  
**Source-layer:** `transportation` (openmaptiles)

The largest single change. Removes all ~46 Liberty road layers and replaces them with ~15 outdoor-first layers that group roads by class AND differentiate paved from unpaved surfaces.

### Removed Liberty layers (46)

7 surface fills, 7 surface casings, 8 bridge fills, 8 bridge casings, 8 tunnel fills, 7 tunnel casings, plus `road_area_pattern`.

### New outdoor road layers (15)

| Layer ID                     | Type | Scope                                             |
| ---------------------------- | ---- | ------------------------------------------------- |
| `outdoor-road-area`          | fill | Plaza/polygon fills                               |
| `outdoor-tunnel-casing`      | line | All road classes in tunnels                       |
| `outdoor-tunnel-fill`        | line | All road classes in tunnels (faded, opacity 0.55) |
| `outdoor-tunnel-path-casing` | line | Paths/pedestrian in tunnels                       |
| `outdoor-tunnel-path-fill`   | line | Paths/pedestrian in tunnels                       |
| `outdoor-major-casing`       | line | Motorway/trunk/primary casing                     |
| `outdoor-medium-casing`      | line | Secondary/tertiary casing                         |
| `outdoor-local-casing`       | line | Minor/service/track casing (darker)               |
| `outdoor-major-fill`         | line | Motorway/trunk/primary (minzoom 5)                |
| `outdoor-medium-fill`        | line | Secondary/tertiary (minzoom 8)                    |
| `outdoor-local-fill`         | line | Minor/service/track (minzoom 12)                  |
| `outdoor-bridge-casing`      | line | All road classes on bridges                       |
| `outdoor-bridge-fill`        | line | All road classes on bridges                       |
| `outdoor-bridge-path-casing` | line | Paths on bridges                                  |
| `outdoor-bridge-path-fill`   | line | Paths on bridges                                  |

### Surface-aware paint

Each surface fill uses `case` expressions on the `surface` field:

| Surface           | Colour                                  | Width       | Dash            |
| ----------------- | --------------------------------------- | ----------- | --------------- |
| `paved` (default) | Normal road colour (MAJOR/MEDIUM/LOCAL) | Class width | Solid           |
| `unpaved`         | Lighter variant                         | Narrower    | `[2, 1.5]` dash |

Unpaved major: `rgb(210, 200, 180)`, medium: `rgb(210, 197, 175)`, local: `rgb(237, 230, 218)`.

Inserted before `road_major_rail`.

Constants: `ROAD_MAJOR_STOPS`, `ROAD_MEDIUM_STOPS`, `ROAD_LOCAL_STOPS`, `ROAD_UNPAVED_STOPS`, `ROAD_TRACK_WIDTH_V2_STOPS`, `ROAD_UNPAVED_DASHARRAY`, `ROAD_TUNNEL_OPACITY`, `COLOURS.ROADS`.

## 18. REPLACE_LIBERTY_POIS

**Toggle:** `REPLACE_LIBERTY_POIS` (default: `true`)  
**Function:** `applyReplacePois(style)`  
**Source-layer:** `poi` (openmaptiles)

Removes Liberty's `poi_r1`, `poi_r7`, `poi_r20` (all urban POI classes at z15+) and replaces them with two catalogue-driven tiers from the same source-layer — the class allowlists, icon map and park rank cap all derive from [`pois/catalogue.yml`](../pois/catalogue.yml). Simplifies `poi_transit` to rail stations and airports only (removes bus stops).

| Layer ID         | Minzoom | Classes                                                                                                                                                                                              |
| ---------------- | ------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `outdoor-poi-z1` | 12      | campsite, castle, information, parking, picnic_site, shelter, drinking_water, park (rank ≤ 6)                                                                                                        |
| `outdoor-poi-z2` | 14      | restaurant, cafe, fast_food, beer, bar, grocery, lodging, hospital, pharmacy, toilets, fuel, bus, ferry_terminal, ice_cream, doctors, bank, atm, post                                                |

- **z1** = the catalogue's tier-1 classes (8), icon + name from z12. `park` carries a `rank_max: 6` cap (`rank <= 6`) so pocket parks don't flood the layer.
- **z2** = the catalogue's tier-2 classes (18), icon + name from z14. Note the remapped classes `beer` (pub) and `ferry_terminal` (ferry) — the names OMT actually emits.

Inserted in-place where `poi_r20` was; the first replacement layer (`outdoor-poi-z1`) becomes the anchor for downstream sections (LOW_ZOOM_PATHS, OUTDOOR_ROUTE, OUTDOOR_POI, MTB_SCALE).

> [!NOTE]
> OMT `poi` data only exists from z14, so z1 renders from z14 in practice — see [Outdoor POIs](pois.md).

**Function:** `applyPathStyling(style)`  
**Source-layer:** `transportation` (openmaptiles)

Restyles `road_path_pedestrian` with trail-brown colour (`#c05a2a`), dash pattern `[1, 0.7]`, and zoom-dependent width. Promotes path name labels (`highway-name-path`) to match the trail colour. The LOW_ZOOM_PATHS overlay handles z9–13; this section owns z14+.

Constants: `PATH_LINE_CAP`, `PATH_LINE_JOIN`, `PATH_DASHARRAY`, `PATH_WIDTH`, `PATH_BASE_MINZOOM`, `COLOURS.PATHS`.
