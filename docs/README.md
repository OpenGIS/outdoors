# Project Documentation

Developer-focused documentation for the [Outdoors](../README.md) codebase — a MapLibre outdoor map style built on OSM Liberty.

## Reading Order

1. [Style Structure](5.style-structure.md) - Layer-by-layer reference: rendering order, feature toggles, colours, and build pipeline architecture
2. [Contours](contours.md) - Hosted PBF contour implementation reference (tile endpoint, layers, zoom ceiling, units)
3. [Outdoor feature tiles (POIs & routes)](features.md) - How the outdoor POI and hiking-route layers are generated (catalogue-driven schema vs Java profile)
4. [How POIs work](pois-concepts.md) - The conceptual model: OSM → OpenMapTiles schema → tiles → style; Maki naming convention; what we keep vs replace from Liberty
5. [Outdoor POIs (catalogue-driven)](pois.md) - Single source of truth for POI rendering: `pois/catalogue.yml` → coverage checker → generated planetiler schema → hosted tiles; tiers and the gap report
6. [Low-zoom paths overlay](paths.md) - Live path tile source at tile.ogis.app/paths (z9–13), generated by the Planetiler profile in docs/examples/FootpathOverlay.java; the style hands off to the base path layer at z14
