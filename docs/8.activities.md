# Activities

> Outdoors is currently activity agnostic.

While the following activity-based overlays were explored, the style is currently activity agnostic, instead of trying to cater to any specific activities. The hiking-route and MTB examples below remain in [`docs/examples/`](examples/) as reference implementations — they are not part of the build. The paths profile ([`examples/FootpathOverlay.java`](examples/FootpathOverlay.java)) is the exception: it is the production source of the low-zoom paths overlay consumed by the style. See [Tile Server](7.server.md).

## Hiking Routes

[![Hiking Routes](examples/hiking-routes.png)](https://www.ogis.org/outdoors/#12/43.65876/-72.83825)

The hiking routes overlay turns OSM hiking route relations (`type=route|superroute`, `route=hiking|foot|walking`) into line vector tiles, so long-distance routes read as a hierarchy on the map.

The Planetiler profile is [`examples/HikingRouteOverlay.java`](examples/HikingRouteOverlay.java), based on Planetiler's [BikeRouteOverlay example](https://github.com/onthegomap/planetiler/blob/main/planetiler-examples/src/main/java/com/onthegomap/planetiler/examples/BikeRouteOverlay.java). It emits an `outdoor_routes` layer (z8–14) — a reference implementation only, with no hosted service behind it.

Thanks to [Waymarked Trails: Hiking](https://hiking.waymarkedtrails.org/#help-about), which has lots of useful information and also offers cycling, mtb, riding (equestrian), skating and slopes (skiing) in addition to hiking.

## MTB Scale

[![MTB Scale](examples/mtb-scale.png)](https://www.ogis.org/outdoors/#14.2/43.1083/-72.90997)

The MTB scale overlay colours ways by mountain bike difficulty, using the [`mtb_scale`](https://wiki.openstreetmap.org/wiki/Key:mtb:scale) tag from the OpenMapTiles transportation source-layer.

This example, based on [this comment](https://github.com/hyperknot/openfreemap/issues/31#issuecomment-4649028862), works well; however, different rating systems exist, like [mtb:scale:imba](https://wiki.openstreetmap.org/wiki/Key:mtb:scale:imba), which — like most other activity-based tags — are not included in the tile schema.
