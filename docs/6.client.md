# Client-side rendering

> `style.json` is validated against the [MapLibre Style Specification](https://maplibre.org/maplibre-style-spec/) at build.

> [!NOTE]
> Currently the style has only been tested with MapLibre GL JS!

> [!WARNING]
> **Known Issues**
>
> - **Metric-only.** The style is metric-only.

## Usage

Loading the style in MapLibre GL JS is a matter of pointing a `Map` at it:

```js
import maplibregl from "maplibre-gl";

const map = new maplibregl.Map({
  container: "map", // a named <div> in your page
  style: "style.json",
});
```

## Metric vs Imperial

The style ships **metric-only**: elevation labels use metres (`m`) — contour labels and the basemap's peak labels. There is no feet variant in the style.

### Contours

Unit switching can be achieved at runtime, before the map parses the style. The compare app does this in [`applyImperialContours()`](../dev/src/App.vue): a recursive expression walker ([`toImperial()`](../dev/src/App.vue)) that converts the `contour-labels` `text-field` from metres to feet — wrapping the `round` argument in `["*", ["get", "ele"], 3.28084]`, swapping the `"m"` suffix for `"ft"`, and leaving the index-contours-only `case` expression intact so only index contours get labelled. The conversion is gated by the `CONTOURS_TO_IMPERIAL` constant in [`dev/src/App.vue`](../dev/src/App.vue).

### Peak Heights

Peak labels are native to the basemap (`Mountain peak labels` / `Volcano peak labels`) and are not patched by the compare app — only the `contour-labels` layer is converted.

## The Compare App

The dev app (`dev/`) renders the outdoor style side-by-side with external providers via `@maplibre/maplibre-gl-compare`. The default comparison provider is the **OpenGIS Basemap** itself — `opengis-basemap` in [`dev/src/providers.json`](../dev/src/providers.json) (label "OpenGIS Basemap", style URL `https://www.ogis.org/basemap/style.json`), selected by `DEFAULT_PROVIDER_KEY` in [`dev/src/composables/useProviderSelection.js`](../dev/src/composables/useProviderSelection.js). The selection is persisted in `localStorage`; providers that require an API key prompt for one, stored locally in the browser only.
