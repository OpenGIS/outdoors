# Client-side rendering

> `style.json` is validated against the [MapLibre Style Specification](https://maplibre.org/maplibre-style-spec/) at build.

> [!NOTE]
> Currently the style has only been tested with MapLibre GL JS!

> [!WARNING]
> **Known Issues**
>
> - **Metric-only.** The style is metric-only.

## Usage

Loading the style in MapLibre GL JS is a matter of pointing a `Map` at it:

```js
import * as maplibregl from "maplibre-gl";
import workerUrl from "maplibre-gl/dist/maplibre-gl-worker.mjs?worker&url";

maplibregl.setWorkerUrl(workerUrl);

const map = new maplibregl.Map({
  container: "map", // a named <div> in your page
  style: "style.json",
});
```

MapLibre GL JS 6.16.0 is ESM-only and ships its worker as a separate module; with a bundler, wire the worker URL (Vite's `?worker&url` import is shown) before creating the map.

## Metric vs Imperial

The style ships **metric-only**: elevation labels use metres (`m`) — contour labels and the basemap's peak labels. There is no feet variant in the style.

### Contours

Unit switching can be achieved at runtime, before the map parses the style. When `CONTOURS_TO_IMPERIAL` is enabled, the compare app does this in [`applyImperialContours()`](../dev/src/App.vue): a recursive expression walker ([`toImperial()`](../dev/src/App.vue)) that converts the `contour-labels` `text-field` from metres to feet — wrapping the `round` argument in `["*", ["get", "ele"], 3.28084]`, swapping the `"m"` suffix for `"ft"`, and leaving the index-contours-only `case` expression intact so only index contours get labelled. The conversion is gated by the `CONTOURS_TO_IMPERIAL` constant in [`dev/src/App.vue`](../dev/src/App.vue).

### Peak Heights

Peak labels are native to the basemap (`Mountain peak labels` / `Volcano peak labels`) and are not patched by the compare app — only the `contour-labels` layer is converted.

## Compare app

The Vue app in `dev/` renders the outdoor style against external providers in a swipe or synchronised side-by-side comparison, with optional DEM overlays on the provider pane and URL-hash camera handling. See [Compare App](13.compare-app.md) for provider selection, view modes, overlays and attribution.
