# Terminology

This glossary defines the vocabulary used across the project.

## Core Concepts

**Allowlist** — The class/kind lists derived from the POI catalogue and baked into layer filters (e.g. `tier1Classes`, `tier2Classes`). A class on the allowlist renders at its tier zoom regardless of OMT rank.

**Anchor** — The layer id relative to which a build section splices its layers, preserving the surrounding stack order. The POI stack's anchor starts at Liberty's `poi_r20` and moves to the first new POI tier layer (`outdoor-poi-z1`) once the Liberty POIs are replaced.

**Base style** — The upstream OSM Liberty style (OpenFreeMap fork) that the build deep-clones and mutates in place. See [Liberty](#dependencies).

**Brunnel** — _Bridge/tunnel_ — the combined bridge/tunnel attribute in the OMT `transportation` layer, used by the road filters to keep bridges and tunnels out of the surface-aware hierarchy.

**Cadence** — The elevation interval of minor contour lines (`CONTOUR_MINOR_EVERY`, 20 m). The cadence must divide the 100 m index interval evenly so minor lines land symmetric between index pairs.

**Casing** — The contrasting outline drawn under a road or path fill.

**Catalogue** — `pois/catalogue.yml`, the single source of truth for the POI system: every POI the style shows, its data source, zoom, icon and label behaviour. Entries are either `ofm` (an OMT class allowlist, with optional `rank_max` density cap) or `custom` (an OSM tag selector for the hosted extract, with `include_when`, `min_zoom` and `show_title`). See [Outdoor POIs](4.pois.md).

**Class** — A value-space term used three ways: OMT feature class (`rock`, `farmland`, `military`, `swimming_pool`…), OMT POI class (`campsite`, `park`, `beer`, `ferry_terminal`…), and mountain-peak class (`saddle`, `volcano`). The POI tiers are class allowlists.

**Compare app** — The Vue dev app (`dev/`) that renders the outdoor style side-by-side with external providers (OpenFreeMap, MapTiler, Thunderforest, Waymarked Trails, Esri, USGS…) via `@maplibre/maplibre-gl-compare`. It also converts contour labels to feet at runtime (`applyImperialContours()`). A static build (`npm run demo:build`) produces the deployable `demo/` output.

**Data floor** — The zoom below which a source carries no data. The OMT `poi` layer's data floor is z14; tiers that want POIs below that (huts from z8, most kinds z10–13) need the custom hosted extract.

**Decimation** — Hiding off-cadence contour lines by painting them at opacity/width 0 rather than filtering them out, because MapLibre GL v5 filter syntax cannot express modulo.

**Extract** — A region of OSM data. Either a Geofabrik extract used as Planetiler input (`geofabrik:italy` for local test builds) or the "custom extract" — the hosted planet build that supplies POIs and paths below the OMT data floor.

**Feature toggle** — A boolean constant at the top of [`scripts/build.mjs`](../scripts/build.mjs) that gates a style section; flip it and rebuild. See [The Style Build](1.build.md).

**Filter** — A style-layer expression that decides which features render. The build targets legacy filter syntax (`$type`, no "Multi-" prefixes) because of MapLibre GL v5 behaviour — see [The Style Build](1.build.md).

**Glyphs** — The font glyph PBFs (`{fontstack}/{range}.pbf`) used for symbol labels; provided by Orange Mug in the base style.

**Hillshade** — The 2D relief-shading layer (`hillshade-layer`) derived from the DEM, fading in across the low zooms.

**Index contour** — The bold contour line at every 100 m (`ele % 100 === 0`), which also carries the elevation label. Contrast _minor contour_.

**Kind** — The custom-POI category field (`hut`, `shelter`, `water`, `viewpoint`, `pass`, `trailhead`…), distinct from the OMT _class_. `ELE_KINDS` are the kinds that also carry an `ele` elevation attribute.

**Layer** — A single styled visual element in the style (id, type, source, paint/layout properties). Build sections add/replace/remove/restyle layers; new layers use kebab-case ids, often `outdoor-` prefixed.

**Minor contour** — The thin contour lines on the 20 m cadence between index lines, decimated at higher zooms.

**Overlay** — A hosted vector source layered on top of the base style: the outdoor POIs, paths and contours served from `tile.ogis.app`. The Planetiler profiles use an `isOverlay()` flag to mark themselves as overlays. See [Tile Server](7.server.md).

**Overzoom** — Rendering tiles beyond their declared maxzoom (the renderer scales up the last available zoom level).

**POI** — _Point of Interest_. The project's POI system is catalogue-driven: `ofm` entries render OMT POI classes at fixed tiers; `custom` entries render hosted-extract kinds; both map to icons in the Maki sprite. See [Outdoor POIs](4.pois.md).

**Promotion / promoted** — Giving track and service roads earlier visibility (from z12), thicker widths and name labels from z13, promoting them beyond base data.

**Rank** — OMT's per-cell POI importance number, used with `rank_max` density caps so dense classes (bus stops, post boxes, city parks) never flood a tile; also the mountain-peak rank (1 vs 2–3) and the park-label rank (`PARK_LABEL_MAX_RANK`).

**Raster-dem** — The MapLibre source type for elevation tiles; the project's instance is the Mapterhorn `demSource`.

**Section** — A build-time style transformation (`apply…()` function) in [`scripts/build.mjs`](../scripts/build.mjs), ordered bottom→top of the render stack and gated by a feature toggle.

**Source** — A data provider in the style: `openmaptiles` (vector base), `ne2_shaded` (raster relief), `demSource` (raster-dem), and the hosted overlay sources `contour-source`, `outdoor-paths`, `outdoor-poi`.

**Source-layer** — The named sub-layer inside a vector source that layers reference (e.g. `outdoor_pois`, `contours`, `mountain_peak`); snake_case.

**Sprite** — The icon sprite sheet (Maki, served by OpenFreeMap as `ofm_f384/ofm`). `icon-image` values are validated against the sprite at build, failing the build on a missing icon rather than rendering nothing.

**Style** — The MapLibre style: `style.json` at the project root, generated by the build from the Liberty base and validated against the MapLibre style spec. It is the only artefact the style needs to ship.

**Surface-aware** — The road hierarchy keyed on paved/unpaved `surface`, with unpaved roads drawn narrower and dashed.

**Terrain** — The 3D elevation rendering enabled by the style's `terrain` property (`{ source: "demSource", exaggeration: 1.5 }`).

**Tier** — A zoom-ordered rendering band. Used for the POI zoom tiers (tier 1 → `outdoor-poi-z1`, z12+; tier 2 → `outdoor-poi-z2`, z14+) and the peak label tiers.

**Tile** — A square (usually 256 px) map tile at zoom z, column x, row y: `{z}/{x}/{y}.pbf` (vector), `.webp`/`.png` (raster).

**Zoom** — The current zoom of the map (usually 0–18 or 0–20). Referred to using the shorthand `z[zoom_number]`, e.g. z12. Features declare zoom ranges via `minzoom`/`maxzoom` (MapLibre's `maxzoom` is exclusive); _overzoom_ happens when the renderer draws tiles beyond their declared maxzoom.

## Dependencies

**Compare-app providers** — The external styles the dev compare app renders against ([`dev/src/providers.json`](../dev/src/providers.json)).

**contour-mvt-server** — The hosted contour service ([acalcutt/contour-mvt-server](https://github.com/acalcutt/contour-mvt-server)) at `tile.ogis.app/terrain`: generates PBF contour tiles on demand with marching squares over the Mapterhorn DEM. See [Tile Server](7.server.md).

**Geofabrik** — The regional OSM extract provider ([download.geofabrik.de](https://download.geofabrik.de/)) used as Planetiler input (`geofabrik:italy` for local builds, the full planet PBF for production).

**Liberty (OSM Liberty)** — The base style this project starts from: [maputnik/osm-liberty](https://github.com/maputnik/osm-liberty), tracked via the [OpenFreeMap fork](https://github.com/hyperknot/openfreemap-styles) `main` branch.

**Maki** — The icon set ([mapbox/maki](https://github.com/mapbox/maki/)) used for POI icons. Liberty builds its sprite from an old snapshot of Maki; the catalogue maps class/kind → sprite glyph name explicitly, with a `marker` fallback and build-time sprite validation.

**MapLibre** — The open-source map renderer the style targets: MapLibre GL JS / Native, the [style specification](https://maplibre.org/maplibre-style-spec/) the build validates against, and the compare widget. npm dependencies: `maplibre-gl`, `@maplibre/maplibre-gl-style-spec`, `@maplibre/maplibre-gl-compare`.

**Mapterhorn** — The DEM provider ([mapterhorn.com](https://mapterhorn.com/)): Terrarium-encoded WebP raster tiles at `tiles.mapterhorn.com` (512 px, maxzoom 17, Copernicus GLO-30 base + national/regional LiDAR). Powers the hillshade, the 3D terrain and — server-side — the contours.

**Natural Earth** — The pre-shaded relief raster inherited from the base style (`ne2_shaded` source, maxzoom 6); not DEM-derived. See [Style Structure](2.style.md).

**Open GIS (ogis.app)** — The hosting project behind `tile.ogis.app`, which serves the POIs, paths and contours.

**OpenFreeMap (OFM)** — The free planet-wide vector tile provider ([openfreemap.org](https://openfreemap.org/)) behind the base style: `tiles.openfreemap.org` (constant `OFM_DOMAIN`), the `ofm` POI catalogue entries, and the sprite (`ofm_f384/ofm`). Also the source of the Liberty fork and of the compare app's Bright/Dark/Fiord/Liberty/Positron styles.

**OpenMapTiles (OMT)** — The vector-tile schema for the base map ([openmaptiles.org](https://openmaptiles.org/)), translating OSM tags into layers such as `poi`, `transportation`, `mountain_peak` and `landcover`. Its zoom-gating shapes the project's data floors: no path geometry below z12, and the `poi` layer emits nothing below z14 — the reason the custom overlays exist.

**OpenStreetMap (OSM)** — The source data for everything: the planet dataset of nodes, ways and relations described by `key=value` tags (`tourism=alpine_hut`, `highway=path`), delivered as planet PBFs or Geofabrik extracts. Attribution: `© OpenStreetMap contributors`.

**Orange Mug** — The font-glyph provider ([orangemug/font-glyphs](https://github.com/orangemug/font-glyphs)) used by the base style's labels.

**Planetiler** — The tile generator ([onthegomap/planetiler](https://github.com/onthegomap/planetiler)) used to build the hosted overlays from OSM data: declarative YAML schemas (the POIs) and imperative Java profiles (the paths), outputting a pmtiles archive. Java profiles require JDK 21+.
