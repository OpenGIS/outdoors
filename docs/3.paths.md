# Paths

> Shifting focus from road networks to navigation by foot.

[![Paths](../screenshots/helvellyn.png)](https://www.ogis.org/outdoors/#11.93/49.97661/-124.45956)

## The OMT Path Gap

The [OpenMapTiles Schema](https://github.com/openmaptiles/openmaptiles) omits path geometry in order to reduce tile file size: nothing below z12, only route-member paths at z12–13, all paths from z14 (references: [Show track/path sooner](https://github.com/openmaptiles/openmaptiles/issues/271), [Selective rendering of tracks and paths at z12-13](https://github.com/openmaptiles/openmaptiles/pull/1190)). The basemap therefore renders no paths at low zoom.

## Path Styling (z14+)

[`applyPathStyling()`](../scripts/build.mjs) unifies the basemap's path family — the distinct `Footway path`, `Bridleway path`, `Cycleway path` and `Steps path` layers plus their tunnel and bridge variants — into the outdoor trail look: the `#c05a2a` trail colour, a dashed `[1, 0.7]` dasharray, butt cap and a shared width ramp. The layers are gated to z14+ (`PATH_BASE_MINZOOM`) so the low-zoom overlay owns z9–13, and tunnels render at 0.55 opacity. The basemap's single `Road labels` layer covers every road class, so path labels keep their basemap colour.

## Low Zoom Paths

In order to make paths visible at lower zooms, a custom extract is created from the planet [OpenStreetMap](https://www.openstreetmap.org/) [dataset](https://www.geofabrik.de/) using [Planetiler](https://github.com/onthegomap/planetiler) and added to the map as an additional vector source (`outdoor-paths`). This path/footway/track geometry is generated with Planetiler and served from the Open GIS `tile.ogis.app/paths`, adding low-traffic, largely off-road ways from z9–13.

[`applyLowZoomPaths()`](../scripts/build.mjs) adds the `outdoor-paths` source (source-layer `outdoor_paths`, z9–13) and three line layers, inserted just before the basemap's `Footway path` layer so the native z12+ path layers take over seamlessly at the overlay's exclusive maxzoom:

| Layer                        | Class filter      | Zooms  | Purpose                                               |
| ---------------------------- | ----------------- | ------ | ----------------------------------------------------- |
| `outdoor-paths-track-casing` | `track`           | z12–13 | Warm brown outline under the track fill               |
| `outdoor-paths-track-fill`   | `track`           | z12–13 | Track-class ways re-drawn as local roads (paved look) |
| `outdoor-paths`              | `path`, `footway` | z9–13  | Path/footway ways in the outdoor trail colour, dashed |

Track-class ways are handled separately because OMT tiles carry only a subset of track geometry below z14.
